# 二手车BG财务日报 — 截图规则交接文档

> 用途：让任意一个能操作 macOS 桌面的机器人/助手，复现"日报 6 张视图截图"这项工作。
> 数据源：每日收到的 `二手车BG财务日报-YYYYMMDD.xlsx`

---

## 一、本质（先搞清楚这件事，否则全错）

用 **Excel 原生「复制为图片」(CopyPicture)** 截取指定单元格区域 → 图片进剪贴板 → 用 `pngpaste` 存成 PNG。

**绝对禁止**：
- ❌ 用 HTML / Playwright / matplotlib 重新渲染表格（会改颜色、改数字、丢格式，用户明确拒绝过）
- ❌ 用 openpyxl 读数值再画图（同上）
- ❌ 用 `screencapture` 截屏幕（会带入菜单栏/其他窗口/缩放模糊）

唯一可接受的方式：**Excel 自己在跑，用 AppleScript 发 `copy picture` 命令**。

---

## 二、环境要求

| 项 | 要求 |
|---|---|
| 系统 | macOS（必须，依赖 AppleScript 驱动 Excel） |
| Excel | Microsoft Excel 必须真实安装并被打开（不是 LibreOffice） |
| Python | `/usr/bin/python3`（3.9，自带 yaml / PIL / openpyxl） |
| 剪贴板工具 | `pngpaste`（`brew install pngpaste`） |
| PATH | 必须同时包含 `/usr/bin`（要 3.9 的 python）和 `/opt/homebrew/bin`（要 pngpaste） |

`PATH` 正确写法：
```bash
export PATH=/usr/bin:/bin:/usr/sbin:/sbin:/opt/homebrew/bin:/usr/local/bin
```
> 两个坑都踩过：只放 homebrew 在前 → python 解析到 3.14、缺 yaml 模块；漏掉 `/opt/homebrew/bin` → 找不到 pngpaste，图全存不下来。

## 三、数据源结构（`日报-汇总` 工作表）

| 位置 | 内容 |
|---|---|
| 第 5 行 | **分组表头（校准基准行，最重要）** |
| 第 6 行 | 列名（日均/昨日/当月累计/YTD…） |
| 第 7 行 | 日期范围（如 `2026/1/1-11/2`） |
| B4 | `数据截止：2026/11/2` |
| 第 9 行起 | 数据区 |

## 四、6 个视图的截图规则

> 列统一截到 **「指标说明」列** 为止（该列是每行的文字说明，是天然的右边界）。
> 下表列字母以 **2026年11月** 为例，**每月会变，见第五节**。

| # | 视图 | 定位锚点（B列文字） | 表头段 | 数据段 | 截图方式 | 特殊处理 |
|---|---|---|---|---|---|---|
| 1 | 二手车BG | `@top`（第一段整块） | 含在整块内 | **B2 : 右边界258**（整块一次截） | 直接截 | 行按 outline ≤2 显示 |
| 2 | 大风车SaaS | `车商SaaS-销售额` | B2:7 | B261:296 | 两段拼接 | — |
| 3 | 268V | `268V-消耗金额` | B2:7 | B298:314 | 两段拼接 | — |
| 4 | 拍卖 | `拍卖&车后-服务费` | B2:7 | B316:327 | 两段拼接 | — |
| 5 | 金服 | `金服-服务费` | B2:7 | B329:349 | 两段拼接 | — |
| 6 | 市场SaaS | `市场SaaS-销售额` | B2:7 | B351:368 | 两段拼接 | **额外**：见下 |

### 市场SaaS 的特殊处理（唯一一个不一样的）

1. **要展开「预算偏差率」那一组列**（连续 7 列：当月预算数/当月偏差额/当月偏差率/YTD预算数/YTD实际数/YTD偏差额/YTD偏差率）
2. 行可见性需要显式设置：**只留 351:368**，隐藏 `9:350` 和 `369:420`
3. 列 outline 用 **≤1**（其他视图是 ≤2）

> 为什么它特殊：市场SaaS 的明细行层级和其他段不同，且预算偏差列默认因 outline 折叠而隐藏，必须单独展开。

**两段拼接 = 表头（B2:第7行）+ 数据段（B第N行:第M行）上下拼成一张图**，否则数据段没有列名，看不懂。

## 五、每月初必做：重新校准列位置（最容易出错的地方）

**Excel 的列布局每月会右移**，且 **各列块的位移量可能不一致**（实测：右边界 +2，但同比/环比/累计只 +1）。
**禁止按单一偏移量推算，必须每月现场读第 5 行实测。**

### 要定位的两个基准

| 基准 | 作用 | 怎么找 |
|---|---|---|
| `指标说明` | 截图**右边界** | 读第 5 行，找到这 4 个字的列 |
| `预算偏差率` | 市场SaaS 要**展开的列块起点**（连续 7 列） | 读第 5 行，找到这 5 个字的列，向右取 7 列 |

### 实测历史（可直接对照）

| 月份 | 截图右边界 | 预算偏差块 |
|---|---|---|
| 2026-09 | EV（第152列） | EO ~ EU |
| 2026-10 | EX（第154列） | EQ ~ EW |
| 2026-11 | **EZ（第156列）** | **ES ~ EY** |

行号相对稳定（261/298/316/329/351），但也建议顺手核对。

### 判断"校准成功"的信号

程序应打印类似：
```
[AUTO] 表头实测: 指标说明=EZ(第156列)=截图右边界, 预算偏差率=ES
[AUTO] saas 展开列块: ES..EY（7列）
```
**这三行没出现，或列字母明显不对，就是校准失败，必须人工介入。**

## 六、三条技术硬规则

1. **行列可见性必须显式控制，不能依赖文件自带的 outline 分组**
   每天发来的文件 outline 结构都可能不同。正确做法：先全部隐藏，再按配置把该显示的行/列显示出来。

2. **列隐藏用 `set hidden of columns`，不要用「列宽设为 0」**
   用宽度 0 会残留细缝、影响相邻列排版。

3. **每次截图后恢复原始行列状态，最后关闭 Excel**
   不恢复会导致下一张图错乱；不关 Excel 用户那边会挂着进程。

## 七、已知故障与对策（都是真踩过的）

| 现象 | 原因 | 对策 |
|---|---|---|
| 图存不下来、clipboard 为空 | `pngpaste` 取剪贴板是**复发型**故障 | 必须自动重试 2~3 次，不能只试一次 |
| AppleScript 超时 30 秒报错 | 批量设 30 多个行区段的可见性，30 秒根本不够（实际需 50~70 秒） | 所有 osascript 调用超时统一设 **180 秒** |
| Excel 打开文件超过 10 分钟 | 文件带外部链接 + 2 万个公式 | 直接截原始文件让 Excel 现算（不要试图用 openpyxl 预处理），并确认"打开时重算" |
| 某列/某行数据是空白 | 文件保存时公式缓存为空（很常见，无 sharedStrings.xml） | **正常现象**，Excel 打开会现算，图是对的，不要以为是坏文件 |
| 截图后 Excel 残留进程 | 未关闭 | 每轮结束 `pkill -9 -f "Microsoft Excel"` |

## 八、每张图必须通过的验收（不通过就不许发）

| 检查项 | 怎么判 |
|---|---|
| 表头 + 数据段完整 | 无空白块、无黑块、无错位 |
| 数据截止日期 | B4 显示 = 目标日期 |
| **本月时间进度** | 必须 = 日 / 当月天数<br>例：11/3 → 3/30 = **10.0%**；11/2 → 2/30 = 6.7%；10/31 → 31/31 = 100.0% |
| 右边界 | 最右列是「指标说明」 |
| 计算列 | 有数字，不是空白或 0 |

> 「时间进度」这一项最容易被忽略却最有用——它能一眼发现"日期对不上 / 月份天数搞错"的低级错误。

## 九、如果要连钉钉发送（附加知识）

1. **图床只能用快域名**：`gh-proxy.com` 实测 0.5~1.1 秒。
   - ❌ 禁用 `gcore.jsdelivr.net`（稳定卡 30 秒）
   - ⚠️ `testingcf.jsdelivr.net` 可用但会被**本机 IP 限速**（校验请求拉多了自己就 20 秒超时）
2. **钉钉发 link 消息时会自己回源去拉图**：源站超过 30 秒 → 返回 `errcode=-1 系统繁忙`，**且用户手机打不开**。
   所以 `-1` 不一定是限流，先怀疑图床慢。
3. `errcode=0` **只证明钉钉收下了消息，不证明用户能看到图**。唯一可靠信号是用户说"看到了"。
4. link 消息的 `title` **用纯中文**（带 ①-⑥ 这类符号会导致 `errcode=-1`）。

## 十、一句话总结给下一个机器人

> 打开 Excel → 读第 5 行定位「指标说明」和「预算偏差率」→ 按 6 个锚点定位数据段 → 显式设置行列可见性 → 用 CopyPicture 把「表头+数据段」截成图 → pngpaste 存 PNG → 按第八节验收。
> **别用 HTML 渲染，别信文件里的公式缓存，每月初必重读表头。**
